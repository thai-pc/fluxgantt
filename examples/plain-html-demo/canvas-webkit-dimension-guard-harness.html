FluxGantt — Canvas WebKit dimension-guard harness (temporary)

Fixture for tests/visual/canvas-renderer-webkit-dimension-guard.spec.ts (spec-canvas-webkit-dimension-limit.md §13.2) only. Reads ?rows=N from the query string, builds N flat 1-day tasks confined to a fixed 1-day timeRange (so physicalWidth stays constant regardless of N — only physicalHeight, and therefore the computed area, varies with the row count), and calls createCanvasRenderer() directly. See src/canvas-webkit-dimension-guard-harness.ts's header comment for the exact row-count boundary math. Result is reported via document.body.dataset.result ("ok" or "error") plus data-error-axis for assertions — same "temporary, ticket-scoped fixture" posture as canvas-harness.html/canvas-a11y-harness.html.
