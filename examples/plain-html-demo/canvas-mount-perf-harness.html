FluxGantt — Canvas mount-time auto-switch perf harness

Fixture for tests/performance/canvas-mount.spec.ts and tests/visual/canvas-auto-switch-boundary.spec.ts (spec-canvas-auto-switch.md §9.2/§10). Reads ?taskCount=N from the query string (default 100) and builds a real createGantt() instance against a synthetic flat dataset — see src/canvas-mount-perf-harness.ts's header comment for the exact dataset shape. Nothing mounts automatically on load: every caller must invoke window.__mountAndTime() itself to trigger and time a real gantt.mount() call (see that file's header comment for why — a genuine cold first mount, not an auto-mounted-then-remounted one, is required for this harness's calibrated performance budgets to mean anything). A separate window.__mountSvgDirectAndTime() hook times a renderer-forced createSvgRenderer() call at the same dataset for the one comparative assertion §9.4c needs. Unlike the other (Ticket 1/2, still-temporary) canvas harnesses in this directory, this one imports everything from the published @fluxgantt/core package — no workspace-source relative imports, since this ticket wires Canvas mode into the real public mount() path.
