FluxGantt — edit hooks fixture

Composes withEditHooks() and implements the documented host recipes: an accessible context menu opened on task:context-requested and a rename dialog opened on task:activated. Query params: ?pad=N (Canvas), ?readonly=1, ?nolinks=1, ?touch=1, ?prevent=0 (host does not call preventDefault()). Drives tests/e2e/edit-hooks.spec.ts.
