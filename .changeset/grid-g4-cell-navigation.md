Grid keyboard cell navigation, after the APG treegrid pattern, for both the SVG and the Canvas renderer. It exists only when `withGrid` is composed: without it every key behaves exactly as before.

Beta: the chart stays ONE Tab stop (the active row) and gains three modes. ROW mode (a row has focus): Right on a collapsed parent expands it; Right on an expanded parent or a leaf enters the first cell; Left on an expanded parent collapses it; Left on a collapsed parent or a leaf moves to the parent row and selects it (nothing happens on a top-level leaf, and the key is then not prevented); Ctrl/Cmd+Home and Ctrl/Cmd+End go to the first and last row. CELL mode (a `gridcell` has focus): Left/Right/Home/End move between the cells of the row (clamped, no wrap), Up/Down/PageUp/PageDown/Ctrl+Home/Ctrl+End move between rows and keep the column, Escape or Left from the first cell returns to the row, and Up on the first row goes to that column's header. HEADER mode (from G3): Left/Right/Home/End between the headers, Alt+Left/Right resizes, Down returns to the cell the header was entered from (or to the first row when it was entered from the row), Escape to the row. Left and Right swap under RTL (the physical key order flips, the logical meaning does not). A cell is script-focusable only (`tabindex="-1"`); Tab never lands on one.

Everything else is deliberately NOT claimed and reaches `keyboard-nav` exactly as from a row, also from a focused cell: Alt+Arrow and Alt+Shift+Arrow (move and resize the task) and Alt+Enter (link), Space, Delete/Backspace (still deletes the selected tasks, NOT "clear cell"), `g`/`G`, Shift+Arrow, Enter (a parent still toggles), F2, undo/redo/duplicate/zoom. Enter and F2 are reserved for the editing PR. A key during IME composition, with Ctrl/Cmd or Shift where the grid does not own the combination, or already default-prevented by an earlier handler, is ignored. Which keys the grid claims is decided synchronously; the actions run from a lazy chunk (the same one as the column resize code), so the very first key may act a moment late, and keys that arrive before it loads are applied in order. A host that bound its own bare Left/Right/Ctrl+Home/Ctrl+End on the chart sees the grid claim them in the capture phase when `withGrid` is composed.

Focus: the focused cell shows a 2 px ring inset in the cell next to the row's focus frame (SVG: one sticky element in the chart layer, created only while a cell has focus; Canvas: painted on the label canvas), in the token colour with `Highlight` in forced colors. Focus survives a repaint (a host `updateTask`, a zoom, a selection change): the SVG chart puts it back on the cell, the Canvas renderer re-focuses the same cell after rebuilding its accessibility layer. Each cell is a real `gridcell` with `aria-colindex`, so a screen reader announces the row, the column header and the value; no container carries an `aria-label`, and the bar keeps its accessible name.

Beta: `GridOptions.resizable: false` no longer takes the header keyboard mode with it. The headers stay script-focusable and navigable (ArrowUp from the first row, Left/Right/Home/End); only the resizing (drag handles, Alt+Left/Right, `resizeGridColumn`) is off. The doc comment on `resizable` says so. WCAG: keyboard access is 2.1.1 (Keyboard); this PR makes no 2.5.7 claim.

Canvas renderer (lazy chunk, `CanvasGridPainter` is internal): a focused cell survives the hidden accessibility layer's rebuild instead of handing focus to the row, the bar ring is not painted while a cell has focus, and `paintCell` draws the ring.

Known limits: Alt+Left/Right still moves the task from a cell (that is the point), so moving across cells is Left/Right only. On Canvas, a cell focused by assistive technology on a row other than the roving row is restored on the roving row. Type-to-edit and editing are a later PR.

Bundle cost (gzip): hello world +0 B, `+ withRender + withInteraction` +0 B, kitchen sink +0 B, `+ withRender + withGrid` +151 B (soft) and the everything gate +120 B (38631 -> 38751), inside the 41.5 KiB limit, which is therefore not raised. The key actions, the cell ring and the Canvas ring are lazy (the `grid/resize-ui` chunk grows from about 1.7 KiB to 2.5 KiB gzip, fetched on first use; `grid/canvas-grid` grows with `paintCell`).
