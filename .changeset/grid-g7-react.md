'@fluxgantt/react': minor
---

Two new opt-in entries that bring the core grid to React: `@fluxgantt/react/grid` exports `<FluxGanttGrid>` (and `useFluxGanttGrid`), and `@fluxgantt/react/grid-editing` exports `<FluxGanttGridEditing>` (and `useFluxGanttGridEditing`). They are `<FluxGantt>` composing `withGrid` (and, for the second, `withGridEditing` after it; `withRtl` stays last). A chart that does not import them ships no grid code: the default `@fluxgantt/react` entry, its props and its API report are unchanged.

Beta (the core grid is `@beta`, so these entries are too): `<FluxGanttGrid>` adds `gridColumns`, `gridOptions` (`collapseBelow`, `durationUnit`, `resizable`) and `onColumnResized` to `<FluxGantt>`'s props; `<FluxGanttGridEditing>` adds `gridEditing` (`isEditable`, `beforeCommit`, `activate`, `commitOnBlur`) and `onCellEditRequested` (call `payload.preventDefault()` synchronously to replace the built-in editor). The ref is the full instance, so it also carries `getGridColumns`, `setGridColumns`, `resizeGridColumn` and `exportGridCsv`, and for the editing entry `startCellEdit`, `cancelCellEdit` and `isEditingCell`.

`gridColumns` is read when the chart is created; a later change is applied with `setGridColumns` (one repaint, never a remount) when the columns differ structurally: ids, widths, headers, bounds, alignment and the identity of the `value`, `format` and `editor` functions. A width the user dragged survives a re-render with the same columns, so persist `payload.widths` from `onColumnResized` and pass them back as `width`. A new function identity on every render (an inline `value` arrow) re-applies the columns on every render and logs ONE dev warning per component: define the functions outside the component or wrap them in `useCallback`. Invalid columns throw a `RangeError` (at construction, wrapped with the usual "invalid initial config" context). `gridOptions`, `activate` and `commitOnBlur` are construction-time only (changing `gridOptions` logs one dev warning; change `key` to remount); `onColumnResized`, `onCellEditRequested`, `isEditable` and `beforeCommit` always follow the latest render.

Bundle cost (gzip, minified, excluding react and core): the default entry grows by about 48 B for the internal seam that the two new entries share (`useFluxGantt` now delegates to a shared hook); the grid entries are measured in the PR.
