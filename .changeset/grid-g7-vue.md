'@fluxgantt/vue': minor

Two new opt-in entries that bring the core grid to Vue: `@fluxgantt/vue/grid` exports `<FluxGanttGrid>` (and `useFluxGanttGrid`), and `@fluxgantt/vue/grid-editing` exports `<FluxGanttGridEditing>` (and `useFluxGanttGridEditing`). They are `<FluxGantt>` composing `withGrid` (and, for the second, `withGridEditing` after it; `withRtl` stays last). A chart that does not import them ships no grid code: the default `@fluxgantt/vue` entry, its props, emits and API report are unchanged.

Beta (the core grid is `@beta`, so these entries are too): `<FluxGanttGrid>` adds the props `gridColumns` and `gridOptions` (`collapseBelow`, `durationUnit`, `resizable`) and the emit `column-resized` to `<FluxGantt>`'s; `<FluxGanttGridEditing>` adds the prop `gridEditing` (`isEditable`, `beforeCommit`, `activate`, `commitOnBlur`) and the emit `cell-edit-requested` (call `payload.preventDefault()` synchronously to replace the built-in editor). The exposed instance is the full instance, so it also carries `getGridColumns`, `setGridColumns`, `resizeGridColumn` and `exportGridCsv`, and for the editing entry `startCellEdit`, `cancelCellEdit` and `isEditingCell`.

`gridColumns` is read when the chart is created; a later change (a new array, a `ref` replaced, or an in-place edit of a reactive array) is applied with `setGridColumns` (one repaint, never a remount) when the columns differ structurally: ids, widths, headers, bounds, alignment and the identity of the `value`, `format` and `editor` functions. A width the user dragged survives an update with the same columns, so persist `payload.widths` from `column-resized` and pass them back as `width`. A new function identity on every change (an inline `value` arrow in a template expression) re-applies the columns each time and logs ONE dev warning per component: define the functions once, outside `setup`. Invalid columns throw a `RangeError` (at construction, wrapped with the usual "invalid initial config" context). `gridOptions`, `activate` and `commitOnBlur` are construction-time only (changing `gridOptions` logs one dev warning; change `:key` to remount); `isEditable` and `beforeCommit` follow the latest prop.

Bundle cost (gzip, minified, excluding vue and core): the default entry grows by about 42 B for the internal seam that the new entries share (the props, emits and event bridge of `<FluxGantt>` are exported to them; `useFluxGantt` delegates to a shared composable); the grid entries are measured in the PR.
