# Quick Start

Render a Gantt chart in about 15 lines. This is the exact code in
[`examples/plain-html-demo/src/main.ts`](https://github.com/thai-pc/fluxgantt/tree/master/examples/plain-html-demo)
— it also appears verbatim in the project README, and a CI check keeps all three copies in
sync.

## The whole thing

```ts
import { createGantt, toTaskId } from '@fluxgantt/core';

const gantt = createGantt({
  tasks: [
    { id: toTaskId('design'), name: 'Design', start: '2026-08-03', end: '2026-08-05', progress: 1, type: 'task' },
    { id: toTaskId('build'), name: 'Build', start: '2026-08-05', end: '2026-08-10', progress: 0.6, type: 'task' },
    { id: toTaskId('review'), name: 'Review', start: '2026-08-10', end: '2026-08-12', progress: 0, type: 'task' },
    { id: toTaskId('launch'), name: 'Launch', start: '2026-08-12', end: '2026-08-12', progress: 0, type: 'milestone' },
    { id: toTaskId('docs-task'), name: 'Write docs', start: '2026-08-06', end: '2026-08-11', progress: 0.2, type: 'task' },
  ],
  dependencies: [
    { from: toTaskId('design'), to: toTaskId('build'), type: 'FS' },
    { from: toTaskId('build'), to: toTaskId('review'), type: 'FS' },
  ],
});

gantt.on('task:moved', (task, prevStart) => {
  console.log(`${task.name} moved from ${prevStart}`);
});

gantt.mount(document.getElementById('gantt')!);
```

You need a container element in the page for `mount()` to render into:

```html
<div id="gantt" style="height: 420px"></div>
```

That's it — you get a rendered chart with draggable bars, a computed critical path (outlined in
dashed red), and a `task:moved` event firing whenever a bar is dragged.

## Line by line

- **`createGantt(config)`** builds a headless `GanttInstance`. Nothing is rendered yet — you can
  already call `gantt.getTasks()`, `gantt.computeCriticalPath()`, `gantt.exportJson()` in Node
  or a test with no DOM.
- **`toTaskId('design')`** brands a plain string as a `TaskId`. IDs are branded types so you
  can't accidentally pass a `DependencyId` where a `TaskId` is expected. `from`/`to` on a
  dependency are `TaskId`s too, hence `toTaskId(...)` there as well.
- **`type`** and **`progress`** are required on every task input (`type` is one of
  `task`/`summary`/`milestone`/`project`; `progress` is `0..1`). `start`/`end` accept an ISO
  date string, a `Date`, or a Temporal value.
- **`type: 'FS'`** is Finish-to-Start — the default. FluxGantt also supports `SS`, `FF`, `SF`,
  plus a `lag` in hours. See [Dependencies](/docs/concepts/dependencies).
- **`gantt.on('task:moved', …)`** subscribes to an event; it returns an unsubscribe function.
- **`gantt.mount(el)`** attaches the SVG renderer and wires drag interactions (unless
  `readOnly` is set).
