# API Surface

A hand-written reference for `@fluxgantt/core`'s public API. (An auto-generated reference will
follow once the API stabilizes past 1.0.)

## `createGantt(config)`

```ts
function createGantt(config: GanttConfig): GanttInstance;
```

Builds a headless `GanttInstance`. Throws if the initial `tasks`/`dependencies` are invalid
(duplicate id, self-link, duplicate pair, or cycle).

## Capability mixins

The base instance is state + compute only. Rendering, interaction and import/export each live
behind an opt-in mixin on its own subpath, so a consumer only downloads what they compose:

```ts
import { createGantt } from '@fluxgantt/core';
import { withRender } from '@fluxgantt/core/render';
import { withInteraction } from '@fluxgantt/core/interaction';
import { withIo } from '@fluxgantt/core/io';

const gantt = withIo(withInteraction(withRender(createGantt({ tasks: [/* … */] }))));
```

| Mixin | Subpath | Adds |
|---|---|---|
| `withRender(instance)` | `@fluxgantt/core/render` | `mount()`, `unmount()`, `refresh()` |
| `withInteraction(instance)` | `@fluxgantt/core/interaction` | No new methods — wires drag/keyboard/click into every `mount()` |
| `withIo(instance)` | `@fluxgantt/core/io` | `exportJson()`, `exportCsv()`, `exportSvg()`, `exportPng()`, `importJson()`, `importCsv()` |
| `withResponsive(instance, options?)` | `@fluxgantt/core/responsive` | `isCoarsePointer()`, `getLabelColumnWidth()` — and adapts density, hit targets, the label column and touch panning under `(pointer: coarse)`. See [Responsive & touch](/docs/responsive) |

Each mixin mutates and returns the SAME instance, so application order does not matter — but
all of them must be applied **before the first `mount()`**: `mount()` reads the interaction
hooks at mount time, so composing `withInteraction` onto an already-mounted instance takes
effect only on the next mount.

The React and Vue wrappers compose `withRender` + `withInteraction` for you.

## `GanttConfig`

| Field | Type | Default | Purpose |
|---|---|---|---|
| `tasks` | `readonly TaskInput[]` | `[]` | Initial tasks. |
| `dependencies` | `readonly DependencyInput[]` | `[]` | Initial dependencies (`{ from, to, type?, lag? }`). |
| `calendar` | `WorkingCalendar` | `DEFAULT_CALENDAR` | Working days/hours/holidays/timezone. Immutable. |
| `viewMode` | `ViewMode` | `'week'` | Timeline zoom (`day`/`week`/`month`/`quarter`/`year`). |
| `density` | `Density` | `'default'` | Row density (`compact` 24px / `default` 32px / `comfortable` 40px / `touch` 48px). `'touch'` is what [`withResponsive`](/docs/responsive) selects under a coarse pointer; you can also set it directly. |
| `locale` | `string` | `'en'` | Renderer locale (dates via `Intl`). **Construction-time only** — read once at `mount()`. |
| `ariaLabel` | `string` | `'Gantt chart'` | Accessible name of the chart as a whole, and the `<title>` of every exported SVG/PNG. Construction-time only. |
| `messages` | `GanttMessages` | — | Accessible-name builders for a non-English host. See [i18n](/docs/i18n). Construction-time only. |
| `readOnly` | `boolean` | `false` | When `true`, `mount()` wires no drag gestures (with `withInteraction` applied; click-select and keyboard nav stay live). |
| `schedulingMode` | `SchedulingMode` | `'manual'` | `'auto'` cascades dependents on move/resize. |
| `initialCollapsed` | `readonly TaskId[]` | `[]` | Tasks to start collapsed. Unknown or leaf ids are dropped silently; fires no `collapse:changed`. |
| `onTaskChange` | `(task, prev) => void` | — | Catch-all fired whenever a task field changes. |

## `GanttInstance` methods

### Tasks

| Method | Returns | Purpose |
|---|---|---|
| `addTask(input)` | `Task` | Add a task; emits `task:added`. |
| `updateTask(id, patch)` | `Task` | Patch fields; emits `task:*` per changed field. |
| `removeTask(id)` | `void` | Remove a task + descendants; emits `dependency:removed`/`task:removed`. |
| `moveTask(id, newStart)` | `Task` | Shift start+end by the same delta; emits `task:moved`. |
| `resizeTask(id, newDuration)` | `Task` | Set duration (working hours); emits `task:resized`. |
| `setProgress(id, progress)` | `Task` | Set progress `0..1`; emits `task:progressed`. |
| `getTask(id)` | `Task \| undefined` | Look up one task. |
| `getTasks()` | `Task[]` | All tasks. |
| `findTasks(predicate)` | `Task[]` | Filter tasks. |

### Dependencies

| Method | Returns | Purpose |
|---|---|---|
| `linkTasks(from, to, type?, lag?)` | `Dependency` | Link two tasks (`type` default `'FS'`); emits `dependency:added`. Throws on cycle/self/duplicate. |
| `unlinkTasks(from, to)` | `void` | Remove links between two tasks; emits `dependency:removed`. |
| `getDependencies()` | `Dependency[]` | All dependencies. |
| `getDependenciesOf(taskId)` | `Dependency[]` | Links touching a task. |

### Hierarchy (collapse / expand)

Base — always present, no mixin required; collapse state is headless.

| Method | Returns | Purpose |
|---|---|---|
| `toggleCollapse(id)` | `void` | Toggle a task's collapsed state, hiding/showing its whole subtree. No-op on a leaf or unknown id. Emits `collapse:changed` iff the set changed. |
| `isCollapsed(id)` | `boolean` | Whether `id` is collapsed **and** still has children. Safe after `destroy()` (returns `false`). |
| `collapseAll()` | `void` | Collapse every task that has children. Idempotent. |
| `expandAll()` | `void` | Expand everything. Idempotent. |

### Computation

| Method | Returns | Purpose |
|---|---|---|
| `computeCriticalPath()` | `CriticalPathResult` | Run CPM; emits `critical-path:computed`. Throws if no tasks / on cycle. |

### Import / Export

Requires the `withIo` mixin (`@fluxgantt/core/io`).

| Method | Returns | Purpose |
|---|---|---|
| `exportJson(options?)` | `ExportBundle` | Serialize to the JSON bundle. Headless. |
| `exportCsv(options?)` | `string` | Serialize tasks to CSV. Headless. |
| `exportSvg(options?)` | `string` | Serialize the mounted chart to an SVG string. Requires `withRender` + mount. |
| `exportPng(options?)` | `Promise<Blob>` | Rasterize the mounted chart to PNG. Requires `withRender` + mount; async. |
| `importJson(input, options?)` | `ImportSummary` | Validate + replace the dataset atomically. |
| `importCsv(csv, options?)` | `ImportSummary` | Same, from CSV. |

(The pure, instance-free `importJson` / `importCsv` functions are also exported from
`@fluxgantt/core/io` — see [Import & Export](/docs/import-export).)

### Events & lifecycle

| Method | Returns | Purpose |
|---|---|---|
| `on(event, callback)` | `UnsubscribeFn` | Subscribe to a `GanttEventMap` event. |
| `mount(container)` | `void` | Render into an element; wires drag unless `readOnly`. Requires `withRender`. |
| `unmount()` | `void` | Remove the rendered chart; keep the instance. Requires `withRender`. |
| `destroy()` | `void` | Unmount + clear listeners; the instance is dead afterward. Base — always present. |
| `refresh()` | `void` | Force a re-render of the mounted chart. Requires `withRender`. |

## `GanttEventMap`

| Event | Payload |
|---|---|
| `task:added` | `(task: Task)` |
| `task:moved` | `(task: Task, prevStart: DateInput)` |
| `task:resized` | `(task: Task, prevDuration: number)` |
| `task:progressed` | `(task: Task, prevProgress: number)` |
| `task:removed` | `(taskId: TaskId)` |
| `dependency:added` | `(dependency: Dependency)` |
| `dependency:removed` | `(dependencyId: DependencyId)` |
| `critical-path:computed` | `(criticalTaskIds: readonly TaskId[])` |
| `collapse:changed` | `(collapsedTaskIds: readonly TaskId[])` — the full collapsed set, not a delta |

`on()` returns an `UnsubscribeFn` (`() => void`).

## Standalone functions & values

| Export | Purpose |
|---|---|
| `toTaskId`, `toDependencyId`, `toResourceId`, `toBaselineId`, `toProjectId` | Brand a string as the matching branded id. |
| `importJson(input, options?)` | Validate + parse a JSON bundle → `{ tasks, dependencies }`. (`@fluxgantt/core/io`) |
| `importCsv(csv, options?)` | Validate + parse CSV → `{ tasks }`. (`@fluxgantt/core/io`) |
| `exportJson`, `exportCsv`, `exportSvg`, `exportPng` | Pure export functions the instance methods delegate to. (`@fluxgantt/core/io`) |
| `IoValidationError` | Thrown by imports on malformed input. (`@fluxgantt/core/io`) |
| `createSvgRenderer`, `layoutRows`, `createTimeScale`, … | Low-level render primitives. (`@fluxgantt/core/render`) |
| `enableDragMove`, `enableDragResize`, `enableKeyboardNav`, … | Low-level gesture recognizers. (`@fluxgantt/core/interaction`) |
| `DEFAULT_CALENDAR` | The Mon–Fri 9–17 UTC default calendar. |
| `isWorkingDay`, `isHoliday`, `addWorkingHours`, `subtractWorkingHours`, `differenceInWorkingHours`, `normalizeDate` | Calendar-aware date helpers. |
| `computeCriticalPath` | The pure CPM function (the instance method delegates to it). |
| `computeRollup(tasks, calendar?)` | Derive each parent's span/progress/duration from its children → `ReadonlyMap<TaskId, RollupResult>`. Pure; never mutates. Throws on a cyclic parent chain. See [Hierarchy](/docs/concepts/hierarchy). |
| `CyclicDependencyError` | Thrown by CPM on a cyclic graph. |
| `signal`, `computed`, `effect`, `batch`, `untracked` | The reactive primitives the store is built on. |
